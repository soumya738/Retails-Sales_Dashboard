# Retail Sales & Merchandising Analytics Dashboard

Interactive Power BI dashboard built on Indian retail store sales data.

## Features
- Executive Overview with KPIs and trends
- Category & Product Performance
- Regional & Outlet Analysis
- Customer & Shipping Insights

## Tools Used
- Python (data cleaning & preparation)
- Power BI + DAX
- SQL-style modeling

## How to use
1. Open `Retail_Sales_Dashboard.pbix` in Power BI Desktop
2. The data is already cleaned and modeled
